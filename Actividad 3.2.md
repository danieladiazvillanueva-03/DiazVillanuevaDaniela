
|                 | **Switch 2**                                                                                                                                      | **Switch 3**                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **¿Qué es?**    | Es un dispositivo de red que trabaja en la capa 2 (enlace de datos), su función principal es conectar dispositivos dentro de una mismo red local. | Es un dispositivo de red que trabaja en la capa 3 (red), combina funciones de una switch tradicional con algunas capacidades de un router. |
| **Diferencias** | Utiliza solo direcciones MAC, conecta dispositivos dentro de una misma red, trabaja con tabla de direcciones MAC.                                 | Utiliza direcciones IP y MAC, conecta dispositivos y enruta redes, trabaja con tabla MAC y de enrutamiento.                                |
